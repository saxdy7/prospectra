## 2. Core Pillars of the Unified Platform

```
┌──────────────────────────────────────────────────────────────────────────────────┐
│                         UNIFIED HYBRID AI PLATFORM                               │
├─────────────────────────┬─────────────────────────┬──────────────────────────────┤
│ 1. SOURCING & SCRAPING  │ 2. TABLE & WATERFALL    │ 3. MULTI-MODAL OUTREACH      │
│  - Google Maps Places   │  - Virtualized Grid     │  - Real-Time Voice AI Bots   │
│  - Job Boards & Careers │  - Waterfall Enrichment │  - Telephony & Webcall Dial  │
│  - People & LinkedIn    │  - Claygent AI Web R&D  │  - Email Sequencer (Campaign)│
│  - Company Lookalikes   │  - Reusable Functions   │  - WhatsApp & SMS Broadcast  │
│  - Webhooks & CSV       │  - Model Context (MCP)  │  - Auto-Job Application Pitch│
└─────────────────────────┴─────────────────────────┴──────────────────────────────┘
```

### Pillar 1: Lead & Job Sourcing (Clay Engine)
- **Local Businesses (Google Maps)**: Target restaurants, contractors, doctors, hotels, etc., with phone, address, rating, and website.
- **Job Finder & Auto-Apply**: Find job openings by title, tech stack, and location. Extract recruiter emails & phone numbers. Auto-generate tailored resumes/cover letters and send multi-step applications.
- **People & Companies**: B2B database search by industry, company headcount, revenue, and seniority.

### Pillar 2: Reactive Spreadsheet & Enrichment (Clay Table + Claygent)
- **High-Performance Table**: Custom columns (Text, Number, Email, Phone, Status, AI Formula, Waterfall, Voice Status).
- **Claygent AI**: Autonomous agent that visits company URLs, checks offerings, identifies decision-makers, and summarizes pitch angles.
- **MCP & Workflows**: Model Context Protocol client/server to interact directly with Claude/ChatGPT/Grok.

### Pillar 3: Real-Time Voice AI & Telephony (Smallest.ai Engine)
- **Voice Agent Studio**: Drag-and-drop / natural language prompt builder with role, objective, customer context variables (`{{name}}`, `{{company}}`), and first messages.
- **Multilingual Support**: Real-time language switching (Hindi, English, Spanish, French, etc.).
- **Voice Library & Cloning**: Featured natural neural voices (Quinn, Magnus, Ella, Rhea) + Instant Voice Cloning.
- **Telephony & Webcall Testbed**: Interactive slide-out testing drawer with instant Webcall simulator, live chat, and international direct dialing (+91 India, +1 USA, +44 UK, etc.).
- **Voice Outreach Campaigns**: Execute batch automated phone calls to scraped leads with conversational AI agents that book appointments or qualify leads.

## 5. Development Phases Breakdown

### Phase 1: Foundation, Design Tokens & Unified Navigation
- Setup layout with dual collapsible sidebar supporting both Clay's GTM data tools and Smallest.ai's Voice AI tools.
- Unified header with AI prompt bar and live credit balance ($/credits).

### Phase 2: Home Workspace & Multi-Product Dashboard
- Greeting + universal AI builder bar (*"Build an Agent or Scrape Leads with natural language"*).
- 6 Action starter cards (Find Leads, Build Voice Agent, Auto-Apply to Jobs, Import Data, Create Campaign, Voice Playground).
- Recent files & Active voice agents preview.

### Phase 3: High-Performance Data Table & Scraper Engine
- Virtualized reactive spreadsheet with 10+ column types.
- Live Google Maps scraper panel & Job search scraper panel.
- Direct row action: *"Launch Voice Call"* / *"Send Cold Email"* / *"Run Claygent"*.

### Phase 4: Voice Agent Studio & Interactive Testing Drawer
- Multi-tab Agent Builder: Prompt, Role & Objective, Context variables, Multi-language switcher (English, Hindi, etc.), Voice selector.
- Live Testing Drawer: Webcall simulator with animated 3D voice orb, Telephony international dialer (+91, +1, +44), and live conversation transcript.

### Phase 5: Voice Playground (TTS, STT & Voice Cloning)
- Text-to-Speech playground with customizable voice speed, pitch, and instant preview.
- Speech-to-Text transcriber.
- Instant Voice Clone generator with microphone record or file upload.

### Phase 6: Job Seeker & Auto-Apply Automation Hub
- Search jobs across sectors -> extract hiring manager details -> generate custom resume/pitch -> trigger automated email sequence or voice introduction call.

### Phase 7: Multi-Channel Outreach & Campaign Orchestrator
- Unified campaigns combining Email Sequences + Automated Voice AI Calls + WhatsApp triggers in one workflow.
- Analytics dashboard with call metrics, open rates, and conversion tracking.
